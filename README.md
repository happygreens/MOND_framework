# M.O.N.D. Framework (Master Blueprint & Hybrid Architecture)

> **Maschinenlesbare Master-Blueprint für KI-Agenten:** [llms.txt](https://raw.githubusercontent.com/happygreens/MOND_framework/main/llms.txt)

Das **M.O.N.D.-Framework** ist eine resiliente, autarke Hybrid-Architektur für PHP-, JavaScript- und CSS-Anwendungen. Es vereint eine mobile-first Benutzeroberfläche mit einer nativen Headless-JSON-Schnittstelle, dreifachen Fallback-Bibliotheken und einer sofort einsatzbereiten Kassenanbindung – völlig unabhängig von teuren Drittanbieter-Plattformen.

---

## ⚡ Kernarchitektur & Hybrid-Fähigkeiten

* **Echte Hybrid-Datei (Full UI & Headless JSON):** Jedes Modul rendert wahlweise eine hochoptimierte, mobile-first Weboberfläche im 4-Stufen-Korsett (Stufe 0 bis 3) oder agiert im reinen Headless-Modus über saubere JSON-Endpunkte (`?json=1` / `?mond_voice=1`) für KIs, Sprachassistenten und IoT-Systeme.
* **Autarkie & Dreifach-Fallback:** Jedes Modul läuft als eigenständige Datei ohne externe Abhängigkeiten auf jedem Server. Durch den 6-stufigen Pathfinder und integrierte Fallbacks dockt es nahtlos an das MOND-Mutterschiff an, sobald dieses vorhanden ist.
* **Zero-Dependency & Termux-Resilienz:** Reines PHP, Vanilla JS und modulares CSS ohne aufgeblähte Frameworks – gehärtet für maximale Kompatibilität (inklusive Android/Termux-Shells).
* **6-Stufen-Lokalisierung (`tl()`):** Universelle Mehrsprachigkeit mit lokalen Fallbacks und Live-Editierbarkeit.

## 💳 Sofort-Monetarisierung über PayHub (0 € Fixkosten)

Ein zentrales Highlight des Frameworks ist die extrem einfache, eingebaute Kassenanbindung über **PayHub** (Stripe / PayPal). Statt komplexer Shop-Systeme oder monatlicher Grundgebühren genügt eine einzige, sprechende URL-Struktur für Einzelkäufe, Abos, Credits oder Buyouts:

```text
https://mond.tv/pay/PRODUKT/PREISEur?vendor=VENDOR
```

* **`PRODUKT`**: Kennung des digitalen Moduls oder Produkts.
* **`PREIS`**: Betrag inklusive Währung (z. B. `19EUR`).
* **`VENDOR`**: Dein persönliches PayHub-Partnerkürzel (z. B. `mario`).

**Faires Revenue-Sharing für Entwickler & Übersetzer:**
* **96 %** verbleiben direkt beim Händler/Entwickler.
* **2 %** fließen in den zentralen Plattform-Betrieb.
* **1–2 %** gehen direkt an Übersetzer und Multiplikatoren.
